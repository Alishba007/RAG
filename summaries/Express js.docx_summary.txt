**What is Express.js?**

Express.js is a web application framework for Node.js that simplifies routing, middleware handling, and HTTP request management. It provides an elegant layer on top of Node's raw http module.

**Working with Requests**

To handle requests, you can use various methods on the `req` object:

* `req.query`: contains URL query parameters
* `req.params`: contains route parameters
* `req.body`: contains data sent in the request body (requires `body-parser` middleware)
* `req.method`: the HTTP method used (e.g. GET, POST)
* `req.url`: the URL of the request
* `req.headers`: contains the headers of the request

**Routing**

Express.js provides several methods for routing:

* `app.get(path, callback)`: for reading/fetching data
* `app.post(path, callback)`: for creating data
* `app.put(path, callback)`: for updating data
* `app.delete(path, callback)`: for deleting data

**Static Files**

You can serve HTML, CSS, JS, and images directly from a folder using the `express.static()` function.

**RESTful API Design**

A RESTful API is an architecture style that defines how clients and servers communicate over HTTP. Express.js provides a simple way to build RESTful APIs with Node.js.

**Example Code**

The text includes an example code snippet that demonstrates how to create a basic RESTful API using Express.js:
```javascript
const express = require('express');
const bodyParser = require('body-parser');

const app = express();

app.use(bodyParser.json());

// ... (code for creating, reading, updating, and deleting items)
```
This example shows how to create an API with four endpoints:

* `POST /items`: create a new item
* `GET /items`: get all items
* `GET /items/:id`: get a single item by ID
* `PUT /items/:id`: update an item by ID
* `DELETE /items/:id`: delete an item by ID
