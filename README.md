# Local-LLM-Client-Chat
A terminal-based chatbot built with LangChain and Ollama using a local Llama 3.1 model.

Project Overview:
This project is a command-line chatbot that runs a local large language model (Llama 3.1) using Ollama and LangChain.
It allows users to interact with the model directly from the terminal without relying on cloud APIs or external services.
